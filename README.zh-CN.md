# Sill

[English](README.md) · **简体中文**

原生 macOS 窗口侧边栏。把窗口放在屏幕边缘，悬停展开，点击即达。

使用 Swift、AppKit 和 SwiftUI 构建，无第三方依赖。

## 功能

- **窗口触手可及。** 显示应用图标、窗口标题与当前窗口高亮，支持切换、最小化和关闭窗口。
- **适合你的桌面。** 左右边缘、四种收起与展开模式、可调尺寸，以及浅色、深色和跟随系统的外观。
- **标题更易读。** 按标题自动选择 300–420 点展开宽度，收起与展开保持列表高度，长标题悬停后完整换行显示。侧边栏设置中仍可选择手动宽度。
- **原生液态玻璃。** 在设置中选择液态玻璃、通透玻璃或经典毛玻璃。液态玻璃需要 macOS 26+，旧版系统自动使用毛玻璃。
- **快速搜索窗口。** 按应用名或窗口标题搜索，支持英文、中文、全拼、拼音首字母，以及混合多关键词。
- **灵活组织。** 同一分组内的同应用窗口相邻排列，支持按应用或可见性分组，选择显示器与窗口范围，排除应用或匹配的窗口标题。
- **可选窗口避让。** 为侧边栏预留空间，并可还原本次运行中自动调整的窗口。
- **原生设置。** 中英文界面、登录启动和菜单栏入口。打开设置时显示 Dock 图标，关闭设置后侧边栏继续运行。

Sill 目前处于早期开发阶段。已支持的行为与待完善部分见[兼容性与验收记录](docs/parity.zh-CN.md)。

## 构建与安装

运行要求：**macOS 14 或更新版本**。构建需要 **Xcode 26+、macOS 26+ SDK 和 Swift 6.2+**，构建机器需支持对应的 Xcode 版本。macOS 14 是部署目标，并不代表所有系统版本和硬件配置均已验证。

克隆并构建：

```sh
git clone https://github.com/microstudent/sill.git
cd sill
swift test
./scripts/build-app.sh
open build/Sill.app
```

构建并安装到 `~/Applications/Sill.app`：

```sh
./scripts/install-app.sh
open ~/Applications/Sill.app
```

覆盖安装前，请先退出正在运行的 Sill。安装脚本会替换该路径下已有的 Sill，并拒绝覆盖 Bundle ID 不同的应用。

上述脚本生成本地开发版本，不是经过公证的发行版本。构建优先使用可用的 Apple Development 签名身份，没有证书时使用临时签名。手动指定签名等选项见[开发文档](docs/DEVELOPMENT.md)（英文）。

## 下载 CI 测试包

打开仓库的 [Actions](https://github.com/microstudent/sill/actions)，选择成功的 CI 运行，在 Artifacts 中下载 `Sill-macos-<架构>.zip`。测试包保留 14 天，需要登录 GitHub 并拥有仓库访问权限。

测试包使用 ad-hoc 签名，尚未经过 Apple 公证，macOS 可能阻止直接打开；它不属于正式发行版。文件名中的架构对应构建机器，并非通用二进制。

## 首次使用

1. 打开 Sill，点击**打开辅助功能设置**。
2. 在**系统设置 → 隐私与安全性 → 辅助功能**中开启 Sill。找不到应用时，可使用**在 Finder 中显示应用**。
3. 将鼠标移到侧边栏上展开列表，点击窗口即可切换。
4. 在**外观与语言**中选择 English、简体中文或跟随系统。

辅助功能权限用于读取窗口标题，以及切换、最小化、关闭和调整窗口。Sill 不需要屏幕录制权限。窗口信息与拼音转换均在本机处理；应用不发起网络请求，不包含统计分析或窗口标题日志。

如果重新构建或更换签名身份后权限失效，请在辅助功能设置中移除旧条目，再添加已安装的应用。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Control` + `Option` + `Space` | 打开窗口搜索，可自定义 |
| `↑` / `↓`、`Tab` / `Shift` + `Tab` | 选择搜索结果 |
| `Return` | 切换到选中的窗口 |
| `Escape` | 关闭搜索面板 |
| `Command` + `W` / `M` / `H` | 在搜索中关闭选中窗口、最小化窗口或隐藏对应应用 |
| `Control` + `Option` + `1` … `9` | 按侧边栏位置切换窗口，需先在设置中开启；可自定义修饰键 |

从侧边栏或 Sill 菜单打开**快捷键…**，即可录制搜索快捷键或修改数字切换的修饰键。设置会自动保存；若与已注册的快捷键冲突，会保留原配置。设置导航在 macOS 26+ 使用所选的原生材质，在旧系统上回退为毛玻璃。

例如，`weixin` 或 `wx` 可以找到“微信”；`yingyongchengxu` 或 `yycx` 可以找到“应用程序”。也支持 `xmsz workspace` 这样的混合搜索。多音字读音遵循系统离线转写结果。

## 当前限制

- 通过 macOS 公开 API 近似识别 Spaces 和可见性，无法提供桌面编号。部分应用仅在访问对应空间后才暴露窗口，窗口切换也可能受系统或目标应用限制。
- 自动窗口避让默认关闭，可能与其他窗口管理器竞争。还原仅限本次运行中调整且之后未再次发生变化的窗口。
- 尚未实现 Command–Tab 替换、按住 Fn 搜索、拖放分组、Dock 角标、全局触控板边缘手势，以及搜索学习和拼写容错。
- 多显示器硬件、Stage Manager、Intel Mac 和登录启动仍需更广泛的验证。
