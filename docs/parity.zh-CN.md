# Contexts 3.9.0 功能对照

[English](parity.md) · **简体中文**

依据：用户截图、本机 Computer Use 读取到的 Sidebar 菜单、官方版本说明。截图内的说明仅作为产品参考。

| 功能 | 本版状态 | 差异或边界 |
|---|---|---|
| 窗口图标与标题列表 | 已实现，已读取真实窗口 | 当前窗口高亮 |
| 四种收起模式与悬停展开 | 已实现 | 隐藏后保留 3 pt 边缘 |
| 左右边缘、上中下对齐 | 已实现 | 基于 visibleFrame |
| 展开宽度、字体与图标大小 | 已实现 | 自动宽度 300–420 pt；手动宽度 180–600 pt；文字 11–20 pt |
| 所有 / 主 / 不显示侧边栏 | 已实现 | 热插拔重建，硬件组合待测 |
| 五种窗口范围 | 已实现 | 可见性通过公开信息近似识别 |
| 自动窗口宽度避让 | 已实现 | 默认关闭，可还原；手动调整后暂停 60 秒为独立开关，默认关闭 |
| 临时隐藏、局部滑动隐藏 | 已实现 | 横向滚动手势待实测 |
| 按 Space 分组 | 部分 | 当前 / 其他与隐藏 / 全屏，无桌面编号 |
| 单组 / 按应用分组 | 已实现 | 增加按应用分组 |
| 手动分组、拖放排序与预留位置 | 未实现 | 需持久窗口匹配与拖放 |
| 无窗口应用 | 已实现 | 激活，不强制新建窗口 |
| 应用和标题过滤 | 已实现 | Bundle ID + 全局标题正则 |
| 中文 / English / 系统语言 | 已完成 UI 切换检查 | 新增即时切换 |
| Light / Dark / System | 已实现 | 系统材质 |
| 液态玻璃 / 通透玻璃 / 经典毛玻璃 | 已实现 | macOS 26+ 原生液态玻璃；旧系统使用毛玻璃 |
| 常规搜索 | 已实现 | Control–Option–Space，中文 / 英文 / 全拼 / 首字母 |
| 搜索学习、单字符容错 | 未实现 | 当前多 token 子串匹配 |
| Fn / 修饰键 Fast Search | 未实现 | 不监听任意键盘输入 |
| Command–Tab 替换 | 未实现 | 保留系统和原版快捷键 |
| 数字切换 | 部分 | 独立快捷键 1–9，非两位编号 |
| 面板关闭 / 最小化 / 隐藏 | 已实现 | ⌘W / ⌘M / ⌘H |
| Dock 角标 | 未实现 | 没有稳定公开跨应用读取接口 |
| 触控板顶部双指手势 | 未实现 | 不使用私有多点触控接口 |
| 登录启动 | 已实现 | 固定路径、签名与系统审批待实测 |
| 更新、原版许可证 | 不适用 | 独立本地开发项目 |
